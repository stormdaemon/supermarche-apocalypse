# Interface : menus

Écran titre « SUPERMARCHÉ APOCALYPSE », pause, game over avec score, meilleur score en localStorage (try/catch).

## Choix de Kevin

- **Écran titre :** les portes automatiques du magasin encore fermées, avec la foule qui s'écrase contre la vitre ; le titre « SUPERMARCHÉ APOCALYPSE » au-dessus.
- **Bouton pour jouer :** « OUVRIR LES PORTES ».
- **Game over :** un ticket de caisse géant qui imprime le bilan (vagues tenues, ennemis éliminés, euros économisés, meilleur score).
- **Pause :** tout se fige, l'image passe en gris avec « PAUSE CAFÉ ».

Code attendu dans `src/features/menus/` (index.ts + config.ts). Ne pas modifier le cœur.
