# Interface : HUD

Vie, numéro de vague, score, compteur de combos, arme équipée.

## Choix de Kevin

- **Vie :** une rangée de petits cœurs qui se vident.
- **Score :** compté en euros économisés, par exemple « 1 250 € économisés ! »
- **Combos :** des étoiles qui s'allument une par une.
- **Arme tenue :** une étiquette de prix jaune qui pendouille, par exemple « Baguette — 0,99 € ».
- **Numéro de vague :** affiché simplement, dans le même style magasin.

Code attendu dans `src/features/hud/` (index.ts + config.ts). Ne pas modifier le cœur.
