# Niveau : rayons destructibles

Rayons dynamiques qui vacillent et basculent sous les gros impacts.

## Choix de Kevin

- **Vacillement :** sous un gros choc, le rayon tangue longtemps et hésite ; on ne sait jamais de quel côté il va tomber.
- **Contenu :** chaque rayon lâche ses propres produits en tombant (bouteilles, légumes, papier toilette…).
- **Ennemis écrasés :** ils rebondissent, projetés en l'air comme sur un trampoline.
- **Après la chute :** le rayon est remis debout à la vague suivante.

Code attendu dans `src/features/destructible-rayons/` (index.ts + config.ts). Ne pas modifier le cœur.
