# Piège : pyramide de conserves

Pyramide de conserves physique qui s'effondre et assomme ceux qui sont dessous.

## Choix de Kevin

- **Contenu :** des pots de cornichons en verre ; ils se brisent à l'impact et laissent le sol glissant.
- **Taille :** une tour qui monte jusqu'au plafond, une vraie avalanche quand elle tombe.
- **Déclenchement :** n'importe quel choc la fait tomber (joueur, ennemi, caddie fou, objet lancé).
- **Pour le joueur :** s'il est dessous, il est assommé aussi ; le piège ne fait pas de jaloux.
- **Retour :** quelques secondes après, les pots se réempilent tout seuls comme par magie.
- **Pancarte devant la tour :** « Record du monde ! »

Code attendu dans `src/features/trap-pyramide-conserves/` (index.ts + config.ts). Ne pas modifier le cœur.
